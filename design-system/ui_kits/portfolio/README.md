# Portfolio UI Kit — tballad.me

High-fidelity recreation of the live portfolio site (CrazyBusyCreative/Portfolio → tballad.me). Use this as a starting point for landing-page variants, case-study templates, or new sections that need to match the existing brand exactly.

## Pieces

- `index.html` — interactive demo: Home → click Projects → see project detail → Contact form flow
- `Nav.jsx` — sticky top nav, brand mark, links, primary CTA
- `Hero.jsx` — homepage hero (display headline + dual CTAs)
- `PageHero.jsx` — inner-page hero (Projects/About/Contact)
- `TrackCard.jsx` — "Two Ways to Work Together" card (eyebrow + display heading + tags)
- `StatRow.jsx` + `Stat.jsx` — 4-up stats with icon + display number
- `ProjectCard.jsx` — featured project card (badge, screenshot, tags, link)
- `ProjectDetail.jsx` — full project section on Projects page
- `Timeline.jsx` + `TimelineEntry.jsx` — orange-rail career timeline
- `StackGrid.jsx` — tech stack tag groups
- `CredentialList.jsx` — check-icon credential rows
- `ContactCard.jsx` — 3-up contact grid card
- `ConvergenceBand.jsx` — atom icon + display quote + link
- `Footer.jsx` — single bordered footer band
- `Button.jsx`, `Tag.jsx`, `Badge.jsx` — atoms
- `Section.jsx` — wraps with optional `--surface` band

## Conventions

- One primary orange CTA per viewport
- All headings use Source Serif 4 (editorial serif, 600 weight, tight tracking)
- Section bands alternate white / `#f8f7f4`
- Container max-width 1000px
